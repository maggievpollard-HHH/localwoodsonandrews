WOODSON ANDREWS WEBSITE

SETUP
- Static HTML, CSS, and JavaScript website maintained in GitHub and published with GitHub Pages.
- Contact form submissions are handled by Formspree.
- No build step or package installation is required.

FILES
- index.html: homepage and contact form
- *-charlotte.html: individual service pages
- about-joe-pollard-cpa.html: About Joe page
- styles.css: shared design and mobile layout
- script.js: mobile menu, current year, and contact-section scrolling
- CNAME: custom domain, charlotte.woodsonandrews.com
- sitemap.xml and robots.txt: search discovery files
- thank-you.html and thanks.html: confirmation pages; the contact form does not currently configure a redirect to either page

PUBLISHING UPDATES
1. Review changes locally, then commit and push them to the GitHub repository:
   https://github.com/maggievpollard-HHH/localwoodsonandrews
2. Use the repository's GitHub Pages deployment configuration to publish. Check the repository's Pages settings for its configured publishing source.
3. Confirm the deployment succeeds, then check https://charlotte.woodsonandrews.com.
4. Keep CNAME consistent with the custom domain configured in GitHub Pages and its DNS records.
5. Check affected pages, navigation, and the mobile layout after publishing.

CONTACT FORM
- The form in index.html posts to https://formspree.io/f/xnpapjwp using method POST.
- Manage submission delivery and notification settings in the Formspree account associated with that form.
- After form changes, send a test submission from the published site and confirm it arrives in Formspree and at the intended notification address.
- Verify the success experience separately; having a local confirmation page does not automatically connect it to Formspree.
